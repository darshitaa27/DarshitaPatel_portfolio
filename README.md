# Darshita Patel - Developer Portfolio

A modern, interactive developer portfolio website suitable for a Software Developer co-op applicant.
Built with React, Vite, Framer Motion, and React Three Fiber.

## 🚀 Getting Started

1.  **Install dependencies** (if you haven't already):
    ```bash
    npm install
    ```

2.  **Start the development server**:
    ```bash
    npm run dev
    ```

3.  **Open in browser**:
    Navigate to `http://localhost:5173` (or the port shown in the terminal).

## 🛠 Tech Stack

-   **Frontend**: React, Vite
-   **Styling**: Vanilla CSS (Variables, Glassmorphism), Lucide React (Icons)
-   **Animations**: Framer Motion
-   **3D Elements**: React Three Fiber, Dreis

## 🎨 Features

-   **Dark Theme**: Deep navy and slate tones.
-   **Glassmorphism**: Modern frosted glass effect for cards.
-   **3D Hero**: Interactive animated orb in the hero section.
-   **Responsive**: Optimized for desktop and mobile.
-   **Sections**: Hero, About, Projects, Education, Skills, Contact.
